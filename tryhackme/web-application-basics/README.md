# Web Application Basics

> Categoria: Web Security
> Plataforma: TryHackMe
> Status: 🔎 Conteúdo pesquisado

## Objetivo
Entender a anatomia de aplicações web antes de explorar vulnerabilidades: URL, requests, responses, métodos, headers e status codes.

## Conceitos
- cliente, servidor e recursos
- URL e seus componentes
- HTTP request/response
- GET, POST e outros métodos
- headers e cookies
- códigos 2xx, 3xx, 4xx e 5xx

## Metodologia
Observar a requisição completa → identificar entrada controlada pelo cliente → observar validação no servidor → verificar resposta e efeitos colaterais.

## Conteúdo pesquisado
A página pública da room descreve exatamente esses fundamentos e os apresenta como base para estudos de segurança web.

## Lições importantes
Segurança web começa com entender o protocolo; muitos problemas surgem quando o servidor confia demais em dados enviados pelo cliente.
