# 🎯 TryHackMe

Esta área concentra rooms e trilhas usadas como laboratório de aprendizagem.

## Status

| Status | Significado |
|---|---|
| ✅ Estudado / evidenciado | Há registro prévio de estudo/prática nesta conversa. Não significa necessariamente conclusão oficial da room. |
| 🟡 Em andamento | O assunto foi iniciado, mas ainda está em progresso. |
| 🔎 Conteúdo pesquisado | A room/conceito foi consultado em fonte pública; não há evidência de conclusão pessoal. |
| ⬜ Não iniciado | Apenas catalogado para estudo futuro. |
