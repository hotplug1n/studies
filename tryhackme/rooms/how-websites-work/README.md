# How Websites Work

> Categoria: Web Fundamentals
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Entender componentes de um site antes de estudar vulnerabilidades.

## Conceitos aprendidos
- cliente e servidor
- front-end e back-end
- requests, responses e URLs
- hospedagem e banco de dados

## Ferramentas
Navegador, DevTools e `curl`.

## Comandos importantes
```bash
curl -I https://example.com
```

## Metodologia
Browser → request → servidor → backend → resposta → renderização.

## O que aprendi
Entendi que a superfície web envolve muito mais que o HTML que aparece no navegador.
