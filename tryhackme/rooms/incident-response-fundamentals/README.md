# Incident Response Fundamentals

> Categoria: Incident Response / DFIR
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Aprender princípios de resposta a incidentes e praticar um fluxo de investigação.

## Conceitos aprendidos
- severidade e tipos de incidentes
- preparação, detecção, contenção, erradicação e recuperação
- playbooks e planos de resposta

## Ferramentas
SIEM, logs, playbooks e recursos de análise.

## Metodologia
Detectar → validar → conter → erradicar → recuperar → lição aprendida.

## O que aprendi
Passei a enxergar incident response como processo organizado e não apenas reação improvisada.
