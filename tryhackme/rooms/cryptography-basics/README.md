Construir base sobre criptografia e cifras simétricas.

## Conceitos aprendidos

## Ferramentas
Terminal, calculadoras e `openssl`.

## Comandos importantes
```bash
openssl version
printf 'texto' | sha256sum
```

## Metodologia
Identificar objetivo → escolher propriedade → compreender chave/algoritmo → validar resultado.

## O que aprendi
Consolidei que criptografia serve a propriedades específicas como confidencialidade, integridade e autenticidade.
