## Objetivo
Entender a relação entre clientes que solicitam serviços e servidores que respondem.

## Conceitos aprendidos
- request/response
- portas e serviços
- cliente, servidor e protocolo

## Ferramentas
Navegador, terminal e `curl`.

## Comandos importantes
```bash
curl -I https://example.com
ss -tulpen
```

## Metodologia
Identificar cliente → serviço → protocolo → resposta → estado da conexão.

## O que aprendi
Consolidei o modelo cliente-servidor como base para entender aplicações web e serviços de rede.
