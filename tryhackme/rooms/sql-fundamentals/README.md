## Comandos importantes
```sql
SELECT * FROM users;
INSERT INTO users(name) VALUES ('test');
UPDATE users SET name='new' WHERE id=1;
DELETE FROM users WHERE id=1;
```

## Metodologia
Conhecer esquema → selecionar operação → testar em dados de laboratório → validar resultado.

## O que aprendi
