# Metasploit: Introduction

> Categoria: Exploitation / Metasploit
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Conhecer os componentes e o fluxo básico do Metasploit Framework.

## Conceitos aprendidos
- `msfconsole`
- módulos, exploits e payloads
- busca e configuração
- sessões

## Ferramentas
Metasploit Framework e AttackBox.

## Comandos importantes
```text
msfconsole
search <termo>
use <modulo>
info
show options
set RHOSTS <LAB_IP>
run
```

## Metodologia
Recon → pesquisar módulo → ler `info` → configurar → executar no lab → analisar sessão.

## O que aprendi
Consolidei o fluxo modular do Metasploit e a importância de entender um módulo antes de executá-lo.
