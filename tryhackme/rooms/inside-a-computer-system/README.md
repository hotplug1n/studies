# Inside a Computer System

> Categoria: Computação
> Plataforma: TryHackMe

## Objetivo
Entender os componentes básicos que formam um sistema computacional.

## Conceitos aprendidos
- CPU, memória e armazenamento
- entrada/saída e periféricos
- relação entre hardware e software

## Ferramentas
Browser e ambiente interativo da room.

## Comandos importantes
```bash
lscpu
free -h
lsblk
```

## Metodologia
Identificar componente → entender função → relacionar com o sistema operacional.

## O que aprendi
Reforcei a visão de baixo nível necessária para entender performance, processos e segurança de um host.
