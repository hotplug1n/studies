# Web Application Basics

> Categoria: Web Security
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Entender a arquitetura básica de uma aplicação web.

## Conceitos aprendidos
- front-end vs back-end
- URLs e HTTP
- web server, database e WAF
- métodos, respostas e headers

## Ferramentas
Browser, DevTools e `curl`.

## Comandos importantes
```bash
curl -I https://example.com
```

## Metodologia
Browser → URL → request → backend → database/serviço → response.

## O que aprendi
Reforcei a ideia de que segurança deve ser aplicada em cada camada e não apenas no front-end.
