# Networking Essentials

> Categoria: Networking
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Aprofundar DHCP, ARP, ICMP, roteamento e NAT.

## Conceitos aprendidos
- DHCP e configuração dinâmica
- ARP e resolução IP/MAC
- ICMP, routing e NAT

## Ferramentas
`ip`, `arp`/`ip neigh`, `ping`, `traceroute`/`tracepath`.

## Comandos importantes
```bash
ip neigh
ping -c 4 8.8.8.8
tracepath example.com
```

## Metodologia
