# Cryptography Concepts

> Categoria: Cryptography
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Fixar conceitos de plaintext, ciphertext, chaves e modelos simétricos/assimétricos.

## Conceitos aprendidos
- confidencialidade e integridade
- algoritmos e chaves
- simétrica vs assimétrica
- combinação de técnicas em aplicações reais

## Ferramentas
Exercícios da room e terminal.

## Comandos importantes
```bash
openssl version
```

## Metodologia
Definir propriedade → escolher mecanismo → identificar chaves → verificar resultado.

## O que aprendi
Passei a separar “algoritmo”, “chave” e “propriedade de segurança” como conceitos diferentes.
