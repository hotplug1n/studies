# OSI Model

> Categoria: Networking
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Usar o modelo OSI para organizar protocolos, encapsulamento e troubleshooting.

## Conceitos aprendidos
- sete camadas
- responsabilidades por camada
- relação OSI/TCP-IP

## Ferramentas
Diagramas, Wireshark e terminal.

## Comandos importantes
```bash
ip addr
ss -tulpen
```

## Metodologia
Sintoma → camada provável → protocolo → evidência → correção.

## O que aprendi
O modelo OSI funciona como uma estrutura de raciocínio para separar problemas de rede.
