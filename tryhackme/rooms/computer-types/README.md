# Computer Types

> Categoria: Pre Security / Fundamentos
> Plataforma: TryHackMe
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Conhecer tipos de computadores e onde diferentes sistemas são encontrados.

## Conceitos aprendidos
- desktops, laptops, servidores e dispositivos especializados
- capacidade de processamento e armazenamento
- relação entre hardware e finalidade

## Ferramentas
Browser, conteúdo interativo da room e terminal quando aplicável.

## Comandos importantes
```bash
uname -a
lscpu
lsblk
```

## Metodologia
Identificar o papel do equipamento → observar recursos → relacionar hardware ao uso.

## O que aprendi
Reforcei que segurança depende também de entender o ativo e sua função dentro do ambiente.
