# Hashing Basics

> Categoria: Cryptography / Password Security
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Entender funções hash, colisões e usos em autenticação e integridade.

## Conceitos aprendidos
- hash de tamanho fixo
- propriedades e colisões
- armazenamento de senhas
- integridade de arquivos
- cracking em contexto de laboratório

## Ferramentas
`sha256sum`, `md5sum`, John the Ripper e outras ferramentas do lab.

## Comandos importantes
```bash
sha256sum arquivo
md5sum arquivo
```

## Metodologia
Identificar formato → gerar/verificar hash → analisar contexto → estudar resistência e uso correto.

## O que aprendi
Reforcei que hash não é criptografia reversível e que senhas exigem algoritmos apropriados de password hashing.
