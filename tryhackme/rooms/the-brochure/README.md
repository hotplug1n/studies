# The Brochure

> Categoria: Linux / Web Exploitation Lab
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Treinar reconhecimento, enumeração e exploração de uma máquina de laboratório.

## Conceitos aprendidos
- enumeração de serviços
- web enumeration
- análise de versão
- exploração e pós-exploração

## Ferramentas
Nmap, navegador, ferramentas web e shell.

## Comandos importantes
```bash
nmap -sC -sV LAB_IP
curl -I http://LAB_IP/
```

## Metodologia
Recon → enumeração → web discovery → validar hipótese → explorar no lab → documentar.

## O que aprendi
Reforcei que a qualidade da enumeração influencia fortemente as próximas etapas.
