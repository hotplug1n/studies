# DNS in Detail

> Categoria: Networking / DNS
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Entender resolução de nomes e seus principais registros e riscos.

## Conceitos aprendidos
- resolvers e authoritative servers
- registros A, AAAA, CNAME e MX
- consultas DNS

## Ferramentas
`dig`, `nslookup`, `tcpdump`, Wireshark.

## Comandos importantes
```bash
dig example.com A
dig example.com MX
```

## Metodologia
Nome → resolver → consulta → resposta → validação e contexto.

## O que aprendi
Consolidei DNS como serviço essencial e também fonte valiosa de evidência em investigação.
