# Digital Forensics Fundamentals

> Categoria: DFIR
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Conhecer investigação forense e preservação de evidências digitais.

## Conceitos aprendidos
- aquisição de evidência
- integridade e cadeia de custódia
- Windows forensics
- análise e relatório

## Ferramentas
Imaging tools, hashes, Event Viewer e ferramentas forenses.

## Comandos importantes
```bash
sha256sum evidence.bin
```

## Metodologia
Preservar → adquirir → validar integridade → analisar → documentar.

## O que aprendi
Reforcei que uma investigação precisa preservar evidências e deixar o caminho de auditoria claro.
