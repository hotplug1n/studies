# Data Representation

> Categoria: Fundamentos
> Plataforma: TryHackMe
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Entender como computadores representam dados internamente.

## Conceitos aprendidos
- bits e bytes
- binário, decimal e hexadecimal
- representação de números e dados

## Ferramentas
Calculadora, conversores e terminal.

## Comandos importantes
```bash
printf '%d\n' 65
printf '%x\n' 255
```

## Metodologia
Converter valores entre bases → interpretar armazenamento → relacionar representação ao funcionamento do computador.

## O que aprendi
Consolidei binário e hexadecimal como ferramentas práticas para redes, memória, hashes e análise técnica.
