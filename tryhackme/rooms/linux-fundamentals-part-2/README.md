# Linux Fundamentals Part 2

> Categoria: Linux
> Plataforma: TryHackMe
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Aprofundar shell, SSH, permissões, flags e manipulação do filesystem.

## Conceitos aprendidos
- acesso remoto via SSH
- flags e argumentos
- copiar/mover arquivos
- permissões e diretórios comuns

## Ferramentas
Bash, SSH e utilitários GNU.

## Comandos importantes
```bash
ssh user@LAB_IP
cp origem destino
mv origem destino
chmod 640 arquivo
```

## Metodologia
Conectar → explorar → alterar arquivos em laboratório → conferir permissões → documentar.

## O que aprendi
Passei a interpretar permissões como parte da segurança do host, e não apenas como detalhe operacional.
