# Search Skills

> Categoria: OSINT / Fundamentos
> Plataforma: TryHackMe
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Desenvolver pesquisas mais precisas e eficientes na Internet.

## Conceitos aprendidos
- operadores de busca
- pesquisa exata e contextual
- filtragem por domínio e tipo de conteúdo
- avaliação da qualidade da fonte

## Ferramentas
Google/Bing, navegador e operadores avançados.

## Comandos importantes
```text
site:example.com
filetype:pdf
intitle:keyword
"exact phrase"
```

## Metodologia
Transformar pergunta em palavras-chave → aplicar operadores → comparar resultados → validar a fonte.

## O que aprendi
Consolidei pesquisa estruturada como habilidade útil tanto para OSINT quanto para troubleshooting e investigação técnica.
