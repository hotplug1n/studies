# Burp Suite: The Basics

> Categoria: Web Security / Tooling
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Conhecer Burp Suite e seu fluxo para testes de aplicações web.

## Conceitos aprendidos
- Proxy e interceptação HTTP(S)
- Target/site map
- HTTP history
- Repeater, Intruder e escopo

## Ferramentas
Burp Suite, navegador e FoxyProxy.

## Comandos importantes
```bash
curl -i http://LAB_HOST/
```

## Metodologia
Configurar proxy → definir escopo → navegar → observar request → enviar para Repeater → testar hipótese.

## O que aprendi
Consolidei Burp como uma central para observar e reproduzir requisições web durante um teste autorizado.
