# Networking Core Protocols

> Categoria: Networking
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Aprofundar protocolos fundamentais da pilha TCP/IP.

## Conceitos aprendidos
- TCP e UDP
- DNS, HTTP e outros protocolos de aplicação
- portas, sockets e estados de conexão

## Ferramentas
`ss`, `netstat`, `dig`, `curl`, `tcpdump`.

## Comandos importantes
```bash
ss -ant
 dig example.com
curl -I https://example.com
```

## Metodologia
Identificar protocolo → porta → estado → payload/metadados → contexto.

## O que aprendi
Passei a correlacionar serviços de rede com portas, transporte e evidências observáveis.
