> Categoria: SOC / Blue Team
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Construir uma base sobre Security Operations Center e praticar triagem de um alerta.

## Conceitos aprendidos
- People, Process, Technology
- detecção e resposta
- alertas e 5 Ws
- atividade legítima vs maliciosa

## Ferramentas
SIEM, logs e ambiente de laboratório.

## Metodologia
Alerta → What/When/Where/Who/Why → evidências → decisão → documentação.

## O que aprendi
Consolidei os 5 Ws como uma forma simples de estruturar a investigação de alertas.
