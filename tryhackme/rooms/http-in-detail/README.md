# HTTP in Detail

> Categoria: Web / Networking
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Aprofundar requests, responses, métodos, headers, cookies e status codes.

## Conceitos aprendidos
- GET, POST, PUT, DELETE e outros métodos
- headers e cookies
- códigos 2xx/3xx/4xx/5xx
- HTTP/HTTPS

## Ferramentas
Browser DevTools, Burp Suite e `curl`.

## Comandos importantes
```bash
curl -i https://example.com
curl -X POST https://example.com/login -d 'user=test'
```

## Metodologia
Observar request → decompor campos → reproduzir → comparar resposta.

## O que aprendi
Consolidei HTTP como uma das principais fontes de contexto em testes de segurança web.
