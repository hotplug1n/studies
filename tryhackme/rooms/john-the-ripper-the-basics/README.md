# John the Ripper: The Basics

> Categoria: Password Security
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Conhecer John the Ripper para auditoria de hashes em laboratórios.

## Conceitos aprendidos
- identificação de hash
- wordlists
- modos de ataque
- verificação de resultados

## Ferramentas
John the Ripper e wordlists do ambiente de treinamento.

## Comandos importantes
```bash
john --wordlist=wordlist.txt hashes.txt
john --show hashes.txt
```

## Metodologia
Identificar formato → selecionar método → testar wordlist → validar resultado → documentar.

## O que aprendi
Consolidei a diferença entre descobrir um hash e auditar sua resistência com técnicas de recuperação em ambiente autorizado.
