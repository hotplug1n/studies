# Putting it all together

> Categoria: Web Fundamentals
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Conectar conceitos de front-end, back-end, HTTP e infraestrutura.

## Conceitos aprendidos
- componentes de aplicações
- fluxo completo de uma requisição
- dependências entre browser, servidor e dados

## Ferramentas
Browser, DevTools e `curl`.

## Comandos importantes
```bash
curl -v https://example.com
```

## Metodologia
Mapear componentes → seguir request → identificar responsabilidade → localizar ponto de controle.

## O que aprendi
Passei a analisar uma aplicação como um conjunto de componentes, o que facilita encontrar onde um controle deve existir.
