## Objetivo
Conhecer tecnologias e conceitos presentes em redes locais.

## Conceitos aprendidos
- LAN
- Ethernet
- switches e hosts
- endereçamento local

## Ferramentas
`ip`, `arp`, simuladores e navegador.

## Comandos importantes
```bash
ip link
ip neigh
```

## Metodologia
Identificar dispositivos → observar endereçamento → entender comunicação local.

## O que aprendi
Reforcei a diferença entre comunicação local e roteada e sua relação com análise de rede.
