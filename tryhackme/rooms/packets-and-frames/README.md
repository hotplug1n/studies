# Packets & Frames

> Categoria: Networking
> Status: ✅ Concluída — evidência visual no perfil

## Objetivo
Entender como dados são divididos e encapsulados na transmissão.

## Conceitos aprendidos
- frames Ethernet
- pacotes IP
- segmentos/datagramas
- cabeçalhos e payload

## Ferramentas
Wireshark e `tcpdump`.

## Comandos importantes
```bash
tcpdump -n -c 20
```

## Metodologia
Capturar → identificar camada → ler cabeçalho → seguir encapsulamento.

## O que aprendi
Passei a observar cabeçalhos e endereços como evidência, não só como detalhes teóricos.

## Documentação de apoio
https://www.wireshark.org/docs/ · https://datatracker.ietf.org/
