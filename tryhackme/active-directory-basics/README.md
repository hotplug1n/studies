# Active Directory Basics

> Categoria: Windows Security / Active Directory
> Plataforma: TryHackMe
> Status: 🔎 Conteúdo pesquisado

## Objetivo
Construir uma visão geral de Active Directory: domínios, controladores, usuários, grupos, trusts, políticas e autenticação.

## Conceitos
- Domain Controller
- domain, tree e forest
- users, groups e OUs
- trusts
- Group Policy
- AD DS
- Kerberos e NTLM em visão geral

## Metodologia de estudo
Entender arquitetura → identificar objetos → compreender autenticação → relacionar políticas e permissões → só então estudar técnicas ofensivas/defensivas.

## Conteúdo pesquisado
A room atual cobre os componentes fundamentais de AD e inclui um laboratório prático. Esta documentação não afirma conclusão pessoal.

## Lições importantes
Em ambientes corporativos, identidade e autorização são parte central da superfície de ataque e também da defesa.
