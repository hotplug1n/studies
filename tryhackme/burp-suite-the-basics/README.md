# Burp Suite: The Basics

> Categoria: Burp Suite / Web Security
> Plataforma: TryHackMe
> Status: ✅ Estudado / evidenciado

## Objetivo
Aprender a configurar o Burp Suite e entender o papel do proxy na inspeção de aplicações web.

## Conceitos
- Proxy e interceptação HTTP(S)
- Target e definição de escopo
- HTTP history e site map
- Repeater
- Intruder
- navegador integrado e configuração de proxy
- certificados para HTTPS em laboratório

## Metodologia
Definir escopo → navegar → observar requests → repetir requests relevantes → alterar um parâmetro por vez → registrar resposta.

## O que eu aprendi
Burp Suite já foi estudado anteriormente e faz parte do foco atual de segurança web. Isso não representa conclusão oficial da room.

## Lições importantes
Escopo bem definido evita testar fora do alvo autorizado e reduz ruído durante a análise.
