# 🧪 Burp Suite

Framework para inspeção e teste de aplicações web em ambientes autorizados.

## Módulos
Proxy, Repeater, Intruder, Target, HTTP history, Decoder, Comparer e extensões.

## Fluxo
Definir escopo → navegar → observar requests → reproduzir no Repeater → testar hipóteses → registrar evidências.
