# 🐧 Linux

## Objetivo
Aprender Linux como sistema operacional de uso diário e como plataforma de administração, defesa e segurança ofensiva em laboratório.

## Tópicos
- filesystem e hierarquia
- usuários, grupos e permissões
- processos e serviços
- pipes, redirecionamento e shell operators
- `grep`, `find`, `awk`, `sed` e `xargs`
- SSH
- gerenciamento de pacotes
- logs e troubleshooting

## Comandos-base
```bash
pwd
ls -la
cd /var/log
find . -type f
ps aux
ss -tulpen
chmod 640 arquivo
chown user:group arquivo
```

## Segurança
Dar atenção a privilégios excessivos, credenciais expostas, serviços desnecessários, permissões inseguras e rastros em logs.
