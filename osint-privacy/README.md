# 🔍 OSINT & Privacy

Coleta e correlação de informação pública de forma ética e verificável.

## Tópicos
Pesquisa aberta, pivôs, validação de fontes, metadados, exposição digital e higiene operacional.

## Método
Pergunta → fontes → coleta → validação → correlação → documentação da evidência.

## Segurança
Nunca usar OSINT para doxxing, perseguição ou coleta indevida de dados pessoais.
